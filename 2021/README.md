## Languages

| Language | Path | Run | Test |
|----------|------|-----|------|
| Rust | `rust/` | `cd rust && cargo run -q --bin dayN < input/dayN.txt` | `cd rust && cargo test --bin dayN` |
| Go | `go/` | `cd go && go run ./dayNN < input/dayNN.txt` | `cd go && go test -race ./dayNN` |
