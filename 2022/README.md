# Advent of Code 2022

Languages: Rust, Zig, Go. Every runner reads the puzzle input on stdin and prints
`Part 1: X` / `Part 2: Y` (day 25 has a single part).

## Run / test

| Language | Run day N | Test day N | Test all |
|---|---|---|---|
| Rust | `cargo run -q --bin dayN < in.txt` (from `rust/`) | `cargo test --bin dayN` | `cargo test` |
| Zig | `zig build run-day_N -- < in.txt` or `zig run src/day_N.zig < in.txt` (from `zig/`) | `zig test src/day_N.zig` | `zig build test` |
| Go | `go run ./dayNN < in.txt` (from `go/`) | `go test ./dayNN` | `go test ./...` |
