# Advent of Code 2023

Solutions in **Rust** (single crate, 2023/rust) and **Go** (2023/go).

## Running Solutions

Each day reads puzzle input from stdin.

### Rust

```bash
cd 2023/rust
cargo run -q --bin dayNN < input.txt
cargo test dayNN::
```

### Go

```bash
cd 2023/go
go run ./dayNN < input.txt
go test ./dayNN
```
