# Advent of Code 2025

## Languages

### Zig
- **Run:** `zig run src/dayN.zig < input.txt`
- **Test:** `zig test src/dayN.zig`

### Go
- **Run:** `go run ./dayNN < input.txt`
- **Test:** `go test ./dayNN`
